# Security Policy

## Reporting a Vulnerability

Please do not publicly disclose security vulnerabilities before they have been reviewed.

When reporting a security issue, include:

- A clear description of the vulnerability.
- Steps required to reproduce it.
- Potential impact.
- Relevant logs or evidence.

Do not include API keys, passwords, access tokens, or other secrets in reports.

## Supported Versions

Security fixes are primarily targeted at the latest version of FRIDAY AI on the `main` branch.
