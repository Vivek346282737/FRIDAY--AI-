# Contributing to FRIDAY AI

Thanks for your interest in contributing to FRIDAY AI.

## Development Setup

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install the project dependencies.
4. Configure the required environment variables using `.env.example`.

## Before Opening a Pull Request

Please:

- Keep changes focused and maintainable.
- Follow the existing project structure.
- Avoid committing secrets or API keys.
- Run Python compilation checks.
- Update documentation when behavior changes.

## Pull Requests

A good pull request should include:

- A clear description of the change.
- Why the change is needed.
- Testing performed.
- Any relevant screenshots or logs.

## Security

Never commit API keys, access tokens, passwords, or private credentials.

For security-sensitive issues, please use the repository's security reporting mechanism rather than publishing exploit details in a public issue.
